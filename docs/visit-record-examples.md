# 방문 기록 작성 예시 (테스트 케이스)

> 용도: 요양사 방문 기록 입력 → AI 요약(`ai_service.generate_summary`) → 보호자 대시보드 흐름을 케이스별로 검증하기 위한 샘플.
> 입력 = `visit_notes`(자유 메모) + 활력징후(`VitalObservation`, LOINC 코드).
> "기대 결과"는 현재 프롬프트·정상범위(`NORMAL_RANGES`) 기준으로 **나와야 하는 방향**이며, 실제 AI 출력 문장은 매번 다를 수 있음.

| # | 케이스 | 검증 포인트 | 활력징후 이상 | 메모 이상 | 기대 anomaly_flags 개수 |
|---|---|---|---|---|---|
| 1 | 정상 방문 | 기본 흐름 | 없음 | 없음 | 0 |
| 2 | 혈압 상승 | 수치 기반 플래그 | 수축기·이완기 | 두통 | 2~3 |
| 3 | 저혈당 의심 | 수치 + 증상 결합 | 혈당 | 식은땀·떨림 | 2 |
| 4 | 발열·호흡기 | 다중 수치 이상 | 체온·SpO₂·맥박 | 기침·가래 | 3~4 |
| 5 | 낙상(안전사고) | 수치 정상, 메모만 이상 | 없음 | 낙상·멍 | 1~2 |
| 6 | 식사·수분 섭취 저하 | 점진적 변화 감지 | 없음 | 식사량·소변 감소 | 1~2 |
| 7 | 인지·정서 변화 | 비신체 영역 | 없음 | 혼동·배회·우울 | 2 |
| 8 | 보호자 요청 처리 | 요청 체크리스트 반영 | 없음 | 없음 | 0 |
| 9 | 방문 거부·부재 | 측정값 없음 처리 | 측정 불가 | 방문 미실시 | 1 |
| 10 | 경계값 | 정상범위 경계(이상·이하) | 경계값 | 없음 | 0 |
| 11 | 식후 혈당 | **오탐(false positive) 확인용** | 혈당 135(식후) | 없음 | 0이어야 하나 1 예상 |
| 12 | 초간단 메모 | 정보 부족 입력 | 없음 | "특이사항 없음" | 0 |

---

## 1. 정상 방문 (기준 케이스)

**visit_notes**
```
09:00~12:00 방문. 아침 식사(죽 1공기, 반찬 3종) 전량 섭취. 아침 약(혈압약) 복용 확인.
세면·옷 갈아입기 보조, 거실 청소. 30분 동안 아파트 단지 산책, 보행 안정적.
기분 좋으시고 손녀 이야기 많이 하심. 특이사항 없음.
```

**활력징후**
| 항목 | LOINC | 값 | 단위 |
|---|---|---|---|
| 혈압(수축기) | 8480-6 | 128 | mmHg |
| 혈압(이완기) | 8462-4 | 78 | mmHg |
| 맥박 | 8867-4 | 72 | beats/min |
| 체온 | 8310-5 | 36.5 | °C |
| SpO₂ | 59408-5 | 97 | % |

**기대 결과**: 요약에 식사·복약·산책 완료가 들어가고 `anomaly_flags: []`

---

## 2. 혈압 상승

**visit_notes**
```
10:00~13:00 방문. 도착 시 뒷목이 뻐근하고 머리가 무겁다고 하심.
어젯밤 잠을 거의 못 주무셨다고 함. 아침 혈압약은 복용하셨다고 하나 약통 확인 결과 어제 저녁분이 남아 있음.
10분 휴식 후 재측정했으나 비슷한 수치. 짠 음식(라면) 드셨다고 하심. 보호자께 연락 권장.
```

**활력징후**
| 항목 | LOINC | 값 | 단위 |
|---|---|---|---|
| 혈압(수축기) | 8480-6 | 162 | mmHg |
| 혈압(이완기) | 8462-4 | 98 | mmHg |
| 맥박 | 8867-4 | 88 | beats/min |
| 체온 | 8310-5 | 36.6 | °C |

**기대 결과**: 수축기·이완기 혈압 초과, 두통 증상, 복약 누락 의심 → 플래그 2~3개

---

## 3. 저혈당 의심

**visit_notes**
```
14:00~17:00 방문. 점심을 거르셨다고 함(입맛 없음). 15시경 손 떨림, 식은땀, 어지러움 호소.
혈당 측정 후 주스 반 컵 드림. 15분 뒤 증상 완화, 재측정 88mg/dL.
당뇨약은 아침에 정상 복용. 이후 간식(빵 1개) 섭취하심.
```

**활력징후**
| 항목 | LOINC | 값 | 단위 |
|---|---|---|---|
| 혈당 | 2339-0 | 58 | mg/dL |
| 맥박 | 8867-4 | 104 | beats/min |
| 혈압(수축기) | 8480-6 | 118 | mmHg |
| 혈압(이완기) | 8462-4 | 72 | mmHg |

**기대 결과**: 저혈당(58), 빈맥(104), 식사 거름 → 요약에 "조치 후 회복"이 포함돼야 함
> 체크: 메모 속 재측정값(88)을 AI가 활력징후 값(58)과 혼동하지 않는지

## 4. 발열·호흡기 증상

**visit_notes**
```
09:00~12:00 방문. 이틀 전부터 기침, 오늘은 누런 가래 있음. 몸이 으슬으슬하다고 하심.
식사 절반만 드심. 물 3컵 드시게 함. 숨이 조금 차다고 하심.
보호자께 병원 진료 권유 문자 드림.
```

**활력징후**
| 항목 | LOINC | 값 | 단위 |
|---|---|---|---|

| 맥박 | 8867-4 | 102 | beats/min |

**기대 결과**: 발열·산소포화도 저하·빈맥·호흡기 증상 → 플래그 3~4개, 요약에 "진료 권유" 포함

```
왼쪽 무릎에 손바닥 크기 멍, 붓기 약간. 걸을 때 통증 호소하나 체중 지지 가능.
냉찜질 15분 실시. 화장실 문턱에 미끄럼 방지 테이프 부착 필요해 보임.
```

**기대 결과**: 수치는 정상이지만 낙상·무릎 멍/통증 플래그가 **반드시** 나와야 함 (메모 기반 탐지 검증)

## 6. 식사·수분 섭취 저하

**visit_notes**
```
10:00~13:00 방문. 최근 일주일째 식사량이 평소 절반 이하라고 하심. 오늘 점심도 1/3 공기.
물을 거의 안 드심(오늘 방문 중 1컵). 소변 횟수 줄었다고 하심. 입술이 건조함.
"배가 안 고프다"고만 하심. 체중계 측정 시 지난달 대비 약 2kg 감소.
```

**활력징후**
| 항목 | LOINC | 값 | 단위 |
|---|---|---|---|
| 혈압(수축기) | 8480-6 | 108 | mmHg |
| 혈압(이완기) | 8462-4 | 68 | mmHg |
| 체온 | 8310-5 | 36.4 | °C |

**기대 결과**: 식욕 저하·탈수 의심·체중 감소 플래그 → 단일 방문이 아닌 "일주일째" 추세가 요약에 담기는지 확인

## 9. 방문 거부·부재

**visit_notes**
```
10:00 방문했으나 문을 열어주지 않으심. 인터폰으로 "오늘은 혼자 있고 싶다"고 하심.
목소리는 또렷함. 10:20 재차 요청했으나 거절. 보호자께 전화로 상황 공유함.
활력징후 측정 못함.
```

**활력징후**: 없음

**기대 결과**: "측정값 없음" 처리, 방문 거부를 이상 사항으로 기록 (플래그 1개). 요약이 수치를 지어내지 않는지 확인

## 11. 식후 혈당 (오탐 확인용)

**visit_notes**
```
12:00 점심 식사 후 14:00 혈당 측정(식후 2시간). 식사·복약 정상. 특이사항 없음.
```

**활력징후**
| 항목 | LOINC | 값 | 단위 |
|---|---|---|---|
| 혈당 | 2339-0 | 135 | mg/dL |

**기대 결과(이상적)**: 식후 2시간 135mg/dL은 일반적으로 정상 범위(<140) → 플래그 0
**예상 실제 결과**: 현재 혈당 정상범위가 70~100(공복 기준) 하나뿐이라 ⚠️가 붙고 플래그 1개 발생 가능

---

## 12. 초간단 메모

**visit_notes**
```
특이사항 없음
```

**활력징후**: 없음

**기대 결과**: 요약이 짧게 "특이사항 없음" 수준으로 나오고, 없는 내용(식사·산책 등)을 지어내지 않아야 함
